# NFL Module Specification

Maturity: planned.

Possible markets include moneyline, spread, totals, and player props. Strategy must explicitly approve each. Required categories are quarterback efficiency, offensive/defensive EPA, success rate, pressure/protection, explosive plays, red-zone performance, injuries, rest/travel, weather, coaching/situational context, and market movement.

Before experimental status, define push/half-point grading, player-status rules, weather freshness, market/line normalization, provider coverage, and calibrated confidence.
