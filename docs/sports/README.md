# Sport Module Specifications

Sport modules describe immutable mechanics and available capabilities. Strategies separately describe what FIND THE EDGE currently approves and prefers.

| Sport  | Maturity     | Definition                    | Strategy                                  |
| ------ | ------------ | ----------------------------- | ----------------------------------------- |
| MLB    | beta         | `packages/sports/src/mlb`     | `strategies/mlb/find-the-edge-v2.1.json`  |
| Soccer | experimental | `packages/sports/src/soccer`  | `strategies/soccer/find-the-edge-v1.json` |
| Tennis | planned      | `packages/sports/src/planned` | `strategies/tennis/planned.json`          |
| NFL    | planned      | `packages/sports/src/planned` | `strategies/nfl/planned.json`             |
| NCAAF  | planned      | `packages/sports/src/planned` | `strategies/ncaaf/planned.json`           |

Promotion requires validated inputs, grading, calibrated methods, provider coverage, fixture/integration tests, and an evaluation decision.
