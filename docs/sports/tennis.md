# Tennis Module Specification

Maturity: planned.

Possible markets include match moneyline, set betting when enabled, and configured player game/set props. Required scouting categories are surface performance, hold/break rates, first- and second-serve performance, return points won, recent form, fatigue and match duration, travel, injury context, tournament format, best-of-three/five, indoor/outdoor conditions, and market movement. Head-to-head receives low default weight.

Before experimental status, define provider coverage, retirement/walkover grading, doubles representation, surface normalization, format-aware features, uncertainty policy, and fixture tests. The planned strategy approves match moneyline only.
