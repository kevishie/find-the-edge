# Moneyline and Spread Analysis

Version: 1.0.0

Analyze only the supplied canonical `moneyline` or `spread` candidate. A spread requires the exact finite point; never invent, round, reverse, or omit it. A two-way moneyline allows only either named participant. A three-way soccer moneyline may also allow the explicit draw selection. Preserve event, participant, market, selection, and price identity exactly. Treat Run Line as MLB display terminology for canonical `spread` only.
