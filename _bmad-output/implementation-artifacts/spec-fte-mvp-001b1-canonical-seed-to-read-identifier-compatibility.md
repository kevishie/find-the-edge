## Intent

**Problem:** A3 produces bounded semantic canonical/participant IDs containing scoped separators and percent-encoding, while FTE-016 read projection validates every internal entity ID as a short external slug. The real seeded B games read therefore fails and C's e2e had to rewrite IDs.

**Approach:** Separate strict external filter-slug validation from bounded internal canonical-entity-ID validation, then prove unchanged A3 seed output flows through B's repository/handler without normalization.

## Boundaries & Constraints

**Always:** Keep external sport/league/status/day query filters on the existing lowercase slug contract. Add a distinct internal canonical ID validator accepting only the exact DATA002 semantic-ID alphabet/encoding produced by `semanticId`: bounded ASCII lowercase slug segments, `:` scope separators, and canonical uppercase `%HH` escapes where required. Reject whitespace, control characters, raw reserved delimiters outside the defined grammar, lowercase/invalid/incomplete percent escapes, empty segments, prototype tricks, and overlength IDs. Apply it only to stored canonical event/participant/league/entity identifiers read from trusted-shape records; projection partition/sort key validation remains exact. Preserve event version/sport/league consistency. Add an integration test that runs real A3 fixture seed with unchanged IDs, then B memory joined read and authenticated handler for MLB/MLS days.

**Block If:** DATA002 semantic IDs are not generated by one stable grammar or exceed a safely bounded Dynamo/API DTO size.

**Never:** Rewrite/sanitize IDs after persistence, weaken external query filters, accept arbitrary printable strings, change semantic ID generation, add UI/runtime config, use e2e-only normalization, add live providers, or touch CDK/IAM.

## I/O & Edge-Case Matrix

| Scenario | Input / State | Expected Output / Behavior | Error Handling |
|----------|---------------|----------------------------|----------------|
| Real seed/read | Unchanged A3 MLB/MLS semantic IDs | B returns canonical games/odds | Success |
| External filter | Colon/percent in sport or league query | Rejected | 400 input error |
| Internal ID valid | Scoped canonical `%HH` semantic ID | Accepted unchanged | No rewrite |
| Internal ID invalid | Bad escape/case/segment/control/overlength | Projection rejected | Typed corruption/input failure |
