# Claude Design Prototype

Imported on 2026-07-15.

This directory contains the Claude Design visual prototype for FIND THE EDGE:

- `Find The Edge.dc.html` — the exported interactive HTML prototype.
- `support.js` — the Claude Design runtime used by the HTML prototype.

Open the prototype locally by opening `Find The Edge.dc.html` in a browser. The HTML references `support.js` with a relative path (`./support.js`), so both files should remain in this directory together.

This prototype is a design reference, not production application code. It should guide visual language, layout density, interaction feel, and component direction, but it does not override product or technical requirements.

Application requirements remain defined by:

- `_bmad-output/planning-artifacts/product-brief.md`
- `_bmad-output/planning-artifacts/prd.md`
- `_bmad-output/planning-artifacts/architecture.md`
- `_bmad-output/planning-artifacts/ux-design-specification.md`
