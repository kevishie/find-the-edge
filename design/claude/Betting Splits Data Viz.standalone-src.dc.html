TURN 1 · BETTING SPLITS — DENSITY STUDY

Encode the divergence, don't narrate it

Today each cell carries three things — handle %, bets %, and a sentence. The sentence is redundant: +25 pts more money is just handle − bets, spelled out. It's also the widest element in the row, so it wins the eye while saying the least.

The signal you're scanning for is one number per market: signed divergence. Big positive means money is heavier than tickets (sharp-side lean). Big negative means tickets outrun money (public-side lean). Everything below encodes that as position or color so a row reads in one pass.

Palette note: I deliberately did not use green here. Green stays reserved for verified +EV. Splits divergence is directional, not good/bad — so it runs purple (money-heavy) against amber (ticket-heavy), with neutral cells staying dark.

WHAT I'D SHIP

1b as the default board. It's the only one of the three where you never do arithmetic — the gap between the bar edge and the notch is the divergence, so outliers like Dodgers spread and total pop out from across the room while a 4-pt Blue Jays gap stays quiet. It also fits three markets in the same width you currently use for one and a half.

Borrow two things from the others: 1a's tint on the row's strongest market only (so one cell per row carries color, not nine), and 1c's signed number as the sort key behind a "max divergence" column.
