# Sportsbook logo provenance

These compact, locally drawn identifiers reference the public BetMGM,
DraftKings, FanDuel, Hard Rock Bet, Caesars Sportsbook, and Circa brand names
and colors solely to identify the source of provider-returned betting data.
They are not endorsements. Update or remove an asset if a sportsbook publishes
revised brand-usage guidance.

Brand references checked 2026-08-03 against the operators' official sites:

- BetMGM: https://sports.betmgm.com/
- DraftKings: https://sportsbook.draftkings.com/
- FanDuel: https://sportsbook.fanduel.com/
- Hard Rock Bet: https://www.hardrock.bet/
- Caesars Sportsbook: https://www.caesars.com/sportsbook-and-casino
- Circa Sports: https://www.circasports.com/

The SVGs are compact Find the Edge renderings rather than redistributed official
artwork. Their accessible names carry the identity if an asset cannot load.

`consensus.svg` is an original Find the Edge identifier for SharpAPI's documented
DraftKings-and-Circa aggregate scope. It is intentionally presented as a combined
source badge, not as a third sportsbook logo or an all-books consensus.
